# Actividad 2 — Git y GitHub

## Objetivo
Practicar el control de versiones con Git y documentar el trabajo realizado en GitHub.

## Estructura
- `documentos/`: cinco capítulos en Word.
- `Informe_de_proceso.pdf`: plantilla de informe con procedimiento, dificultades, soluciones, conclusiones y espacios para evidencias.
- `comandos_git.txt`: resumen de comandos.

## Procedimiento
1. Crear un repositorio en GitHub.
2. Clonarlo localmente con `git clone URL`.
3. Crear o modificar archivos.
4. Revisar cambios con `git status` y `git diff`.
5. Preparar archivos con `git add`.
6. Confirmar con `git commit -m "Mensaje descriptivo"`.
7. Publicar con `git push`.
